# Размещение SnowEnduro CRM

Публичный интерфейс CRM размещается отдельно на GitHub Pages: `https://felseeker.github.io/snowenduro-crm/`. Сайт `snowenduro.ru` остаётся на GitHub Pages.

API работает в Yandex Cloud Functions, данные хранятся в отдельной бессерверной базе YDB в папке `SN snowenduro-crm`. API доступен через HTTPS API Gateway. Docker и Supabase не используются.

## Первичный запуск

1. Добавьте в переменные Cloud Function `SETUP_TOKEN` — случайный одноразовый код для создания первого администратора.
2. Откройте ссылку CRM и создайте администратора со своим email и паролем не короче 12 символов.
3. После создания администратора удалите `SETUP_TOKEN` из переменных Cloud Function.

CRM сохраняет заявки, статусы и комментарии менеджера в YDB. Фотографии каталога хранятся там же. Клиентские данные и секреты не входят в публичные репозитории.

## Синхронизация каталога

CRM ставит публикацию в очередь API. GitHub Actions сайта забирает опубликованный каталог, обновляет статические карточки и сообщает CRM результат сборки.

Для синхронизации задайте в Function секрет `SYNC_CALLBACK_TOKEN`, а в репозитории `felseeker/snowenduro-site` — Actions secret `CRM_SYNC_CALLBACK_TOKEN` с тем же значением. В Actions Variables задайте адреса API каталога, очереди и callback из настроек CRM. Токен храните только в секретах, не в исходниках.

При ошибке GitHub Actions показывает статус workflow; CRM сохраняет результат публикации и позволяет повторить её. Уже опубликованный сайт продолжает показывать последнюю успешную версию каталога.

## Заявки с сайта и Telegram

Приём заявок с публичного сайта оставлен выключенным. Перед включением обновите страницу `/privacy` и текст согласия под фактическую обработку данных, затем проверьте применимые требования к персональным данным.

Telegram необязателен и пока не подключён. Когда будете готовы, добавьте токен бота в секрет `TELEGRAM_BOT_TOKEN` Function, а Chat ID получателей — в настройках CRM. В уведомлениях передаются номер заявки и безопасное описание интереса, без имени и телефона клиента.

## Стоимость и резервные копии

YDB ограничена 1 ГБ и 10 RU/с; текущая конфигурация не использует выделенную пропускную способность. Бесплатные квоты Yandex Cloud общие для аккаунта, поэтому превышение может тарифицироваться.

В этой версии отдельная автоматическая резервная копия не настроена. До ввода реальных данных включите расписание резервного копирования YDB и периодически проверяйте восстановление копии.
