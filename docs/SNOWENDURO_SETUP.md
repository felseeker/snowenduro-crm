# Запуск SnowEnduro CRM

## Windows

1. Установите Node.js 24.
2. Запустите `Start-SnowEnduroCRM.cmd`.
3. Откройте в браузере `http://127.0.0.1:4173` и создайте администратора с паролем от 12 символов.
4. Не закрывайте окно запуска, пока пользуетесь CRM. Чтобы остановить сервер, закройте это окно.

Первый запуск установит зависимости и соберёт интерфейс. База и фотографии хранятся в `%LOCALAPPDATA%\SnowEnduroCRM\data`, отдельно от проекта и OneDrive. Каталог заполняется публичными карточками SnowEnduro; клиентских примеров в нём нет.

## Telegram

Бот необязателен. Создайте его через @BotFather и сохраните токен в `%LOCALAPPDATA%\SnowEnduroCRM\.env` как `TELEGRAM_BOT_TOKEN=...`. Получатели нажимают `/start`; затем найдите их чаты в разделе «Telegram» и сохраните нужные Chat ID. Токен не передаётся в браузер, имя и телефон клиента не уходят в уведомления.

## Публикация каталога

Чтобы CRM запускала обновление каталога сайта, сохраните серверный токен GitHub с правом записи только в `felseeker/snowenduro-site` и случайный `SYNC_CALLBACK_TOKEN` в `%LOCALAPPDATA%\SnowEnduroCRM\.env`. Этот же callback-токен добавляется в секрет `CRM_SYNC_CALLBACK_TOKEN` в GitHub Actions сайта. Переменные Actions `CRM_PUBLIC_PRODUCTS_URL` и `CRM_SYNC_CALLBACK_URL` должны указывать на доступный HTTPS API CRM.

Локальная CRM на `127.0.0.1` не доступна GitHub Actions или посетителям сайта, поэтому каталог и формы с сайта с ней не синхронизируются. Не задавайте локальный адрес как публичный API.

## Настоящие заявки с сайта

GitHub Pages размещает только статические файлы. Чтобы сайт принимал и сохранял заявки, нужен доступный по HTTPS сервер CRM в России с постоянным хранилищем. В этой версии такой сервер не подключён, публичная форма остаётся выключенной. Не вносите реальные клиентские данные в публичную страницу CRM.
