# Запуск SnowEnduro CRM

## Локальный запуск

1. Установите Node.js 24.
2. В каталоге CRM выполните `npm ci` и `npm run dev`.
3. Откройте `http://127.0.0.1:4173` и создайте администратора с паролем от 12 символов.
4. CRM создаст SQLite-базу и заполнит каталог исходными публичными карточками товаров.

Для обычного запуска после сборки выполните `npm run build`, затем `npm start`. Docker и отдельная база данных не нужны.

По умолчанию сервер доступен только с компьютера, на котором запущен. Значения `HOST`, `PORT` и `CRM_DATA_DIR` при необходимости задаются в локальном `.env`; образец находится в `.env.example`. При первом удалённом запуске задайте длинный случайный `SETUP_TOKEN`, чтобы посторонний не смог создать администратора.

## Telegram

Бот необязателен. Если нужны уведомления, создайте его через @BotFather и добавьте `TELEGRAM_BOT_TOKEN` в `.env` на сервере. Каждый получатель должен отправить боту `/start`; после этого добавьте его Chat ID в разделе «Telegram». В уведомлении нет имени и телефона клиента.

## Синхронизация каталога сайта

Сайт получает каталог через существующую GitHub Actions-сборку. После установки workflow в `snowenduro-site` добавьте на CRM-сервер GitHub-токен с правом `Contents: write` только для этого репозитория и случайный `SYNC_CALLBACK_TOKEN`. Тот же callback-токен добавляется в секрет GitHub Actions `CRM_SYNC_CALLBACK_TOKEN`; адреса API задаются переменными репозитория. Из CRM передаются только опубликованные карточки товаров. Фотографии, добавленные через CRM, копируются в репозиторий сайта во время сборки.

## Перед публикацией

GitHub Pages размещает только статические файлы, поэтому там нет Node.js-сервера и базы. Не подключайте к этому адресу настоящую форму и не вносите реальные персональные данные. Для общей CRM с сайта потребуется разместить приложение и API на сервере с HTTPS и резервными копиями. Автоматическая публикация каталога работает после установки workflow и серверных секретов. Публичная форма остаётся выключенной, пока `/privacy` не описывает фактическую обработку и не проверен текст согласия. Для её включения переменная сборки `NEXT_PUBLIC_CRM_LEADS_ENABLED` должна иметь значение `true`; без неё данные не отправляются.

База и фотографии хранятся в `data/`. Копируйте оба пути для резервного восстановления. Эти файлы исключены из Git.
