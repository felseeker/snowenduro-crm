# Размещение SnowEnduro CRM

## Текущая версия

CRM запускается на одном компьютере: Node.js 24, интерфейс и API работают вместе, база — SQLite. Docker, Supabase и облачные ресурсы не используются. Публичный сайт остаётся на GitHub Pages.

Для Windows запустите `Start-SnowEnduroCRM.cmd`. Программа хранит базу и фотографии в `%LOCALAPPDATA%\SnowEnduroCRM\data`, вне папки проекта и синхронизации OneDrive. Файл секретов, если он понадобится, находится в `%LOCALAPPDATA%\SnowEnduroCRM\.env`.

Страница открывается вручную по адресу `http://127.0.0.1:4173`. Сервер слушает только этот компьютер. Закройте окно запуска, чтобы остановить CRM.

## Что пока не включено

- Статическая страница GitHub Pages не может работать как сервер и не хранит заявки. Поэтому публичная форма сайта не подключается к локальной CRM и остаётся выключенной.
- Для получения заявок с сайта и общего доступа менеджеров нужен HTTPS-сервер с постоянным хранилищем данных в России. В этой версии такой сервер не создаётся.
- Публикация каталога через GitHub Actions станет доступна после добавления секретов GitHub и callback в закрытый файл `.env` CRM, а URL и callback-секрета — в настройки Actions сайта.
- Telegram-уведомления включаются только после добавления токена бота. Каждый получатель сначала отправляет боту `/start`, затем его Chat ID добавляется в CRM. В уведомлениях нет имени и телефона клиента.

Не вносите реальные данные клиентов в публичный интерфейс GitHub Pages. Перед приёмом реальных обращений обновите документы сайта о персональных данных и проверьте порядок получения согласия и применимые требования российского законодательства.

## Резервная копия

Остановите CRM и скопируйте `%LOCALAPPDATA%\SnowEnduroCRM\data` в защищённое место. В папке находятся SQLite-база и фотографии товаров. Не помещайте копию в публичный GitHub-репозиторий.
