# Первый вход в SnowEnduro CRM

CRM размещается отдельно от сайта по адресу `https://felseeker.github.io/snowenduro-crm/`. Вход открывается после настройки API в Yandex Cloud.

При первом запуске нужен `SETUP_TOKEN`, заданный владельцем в секретных переменных Cloud Function. Введите этот код на странице настройки CRM и создайте свой аккаунт администратора с паролем не короче 12 символов. Код удаляется из Function после создания администратора.

После входа доступны заявки, каталог, Telegram и настройки. Заявки с сайта пока не принимаются: перед включением обновите документы и согласие на сайте.

## Telegram

Подключите бота позже, когда будете готовы: добавьте его токен в секрет `TELEGRAM_BOT_TOKEN` Cloud Function, затем сохраните Chat ID получателей в CRM. Для получения Chat ID каждый получатель должен начать диалог с ботом. В Telegram не отправляются имя и телефон клиента.
